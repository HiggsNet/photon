# Photon v0.6.1

v0.6.1 在 Linux v0.6.0 基础上合入已有 Windows 客户端，Windows 与 Linux 使用同一份共享核心、版本号及发布流程。保留 v0.6.0 的 IPsec 接口宣告与跨来源回退。

## 两项共享 Gossip 修复

- **多地址回退**：UDP 按地址记录发送失败，最近失败不再被旧成功记录掩盖。TCP 保留 observed/grace、bootstrap 和签名候选，在统一 5 秒预算内依次尝试，并独立记录 TCP 地址质量；网络失败可换地址，本机容量、取消和协议响应错误不会触发额外 UDP bulk transfer。
- **分片缓存生命周期**：首轮发送结束的补包缓存按需淘汰，正在发送的传输受保护；相同快照复用传输，永久发送失败立即释放。保持每 peer 4 条和 32 MiB payload 上限，新增全局 1024 条限制。容量不足记录具体限制与占用，合并重复警告，不再误报 invalid_message。

## Windows 与产物

- Windows 11 amd64：原生窗口与托盘、首次身份初始化、入网请求、网关选择、Wintun 分流隧道、日志及节点诊断；已有 SCM 服务入口继续保留。
- Windows 便携 ZIP 含程序、固定 SHA-256 的官方 Wintun 0.14.1 DLL、中文说明、示例配置及许可证。默认不提供实际 config.yaml，不打包数据库、私钥或日志。
- Linux amd64/arm64：原生安装包及容器镜像，正式版本更新 ghcr.io/higgsnet/photon:latest。
- 发布同时提供各归档的 SHA256 校验文件，Windows 包内另附 SHA256SUMS。

## 升级与验证范围

- 从 v0.6.0 或 RC.13 升级不新增数据库 schema、Gossip wire 或签名格式迁移。早于 schema 2 的版本仍走既有启动事务迁移；升级前备份配置、身份和一致数据库，回退旧版须恢复旧数据库。
- Windows 升级前退出旧托盘或停止占用同一数据库的服务，再解压到独立目录并显式选择原配置和数据库。
- 本次共享修复通过隔离全量测试、相关竞态检查、完整 smoke 及本机真实 TCP 拉取/UDP 回退测试；Windows 11 实机四组原生回归共 527 项顶层测试通过：Gossip 132、Host 112、Windows 平台 214、桌面 69；17 项需要额外网卡或 GUI 集成开关的测试明确跳过，其中 Gossip/Host 无跳过。原生回归同时修正了 Windows 超长 UDP 报文分类，并将 Linux 适配器测试限定到 Linux。发布流程另执行 Windows 原生客户端测试与便携包校验。
- Windows 主程序尚无 Authenticode 签名；72 小时 soak、物理睡眠/换网和高 DPI 完整矩阵仍保留原验收边界。本次发布不代表这些场景已完成，也不包含生产节点部署。
