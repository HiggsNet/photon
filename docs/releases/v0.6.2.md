# Photon v0.6.2

- Windows 客户端支持与多个授权节点直连。修复定时 IPsec CHILD SA 换钥后旧隧道清理导致的断连。
- Windows 诊断界面按概览、隧道和节点整理，自动刷新时保留当前选择。主窗口、设置和诊断窗口按显示器工作区调整初始位置，避免被任务栏遮挡。
- 修正 Nix 打包的 Go 依赖校验值。Flake 和传统 Nix 入口均保留固定哈希校验。

本版提供 Linux amd64/arm64 安装包和容器镜像，以及含 Wintun 的 Windows amd64 便携包。下载后可用随附的 SHA256 文件校验归档。Windows 升级前先退出旧托盘或停止服务，再将新包解压到独立目录并选择原配置。具体步骤见 [Windows 使用说明](https://github.com/HiggsNet/photon/blob/v0.6.2/docs/photon-windows/README.zh-CN.txt)。
