# Photon v0.6.3

- Linux XFRM 使用 rtnetlink 查询链路和地址、创建和搬迁接口、修复链路标志以及增删地址。已有命名空间的转发开关直接通过 `/proc/sys` 对账，减少空闲巡检启动的短命令。首次创建命名空间和兼容回退仍使用 `ip`。
- Gossip 在单次会话中合并重复的目录分页请求。旧目录触发的拉取返回不同摘要时，如果本机已独立验证并提交返回版本，就结束该次拉取，避免整轮退避。缺少该版本时继续校验快照摘要。
- Gossip 复用已计算的本地目录摘要和同一入站地址确认中的授权链验签结果，减少重复计算和分配。
- Linux 停止发布及续签 `routing/babel/identities`，已有记录自然过期。Babel Router ID 保持原有行为。

本版提供 Linux amd64/arm64 安装包与容器镜像，以及含 Wintun 的 Windows amd64 便携包。下载后可用随附的 SHA256 文件校验归档。
