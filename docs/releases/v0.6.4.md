# Photon v0.6.4

- Gossip 刷新节点地址簿时，只复制端点记录和发现所需的授权、撤销及 checkpoint 数据。返回的视图与已提交状态隔离。
- 同一次发现刷新只对每个已有 zone 验证一次授权链，验证结果也用于发现该 zone 授权的子节点。
- 在 26 个签名节点的本地基准里，端点与时间戳不变时，每次刷新分配量从约 264 KiB 降至 120 KiB。

- Windows Mesh 在后台处理授权刷新、IKEv2 建连和换钥准备，数据面直接读取已发布的授权版本。控制报文与 ESP 分开排队发送。
- Windows Mesh 在授权版本交接时短暂保留仍有效的已安装授权，继续执行原有的到期检查。Babel 源序号前进时才同步邻居。
- Windows 诊断界面修复状态轮询导致的按钮闪灰，日志采用增量追加。

本版提供 Linux amd64 和 arm64 安装包与容器镜像，以及含 Wintun 的 Windows amd64 便携包。归档附有 SHA256 校验文件。
