# Photon v0.6.5

- Windows Mesh 将发送和接收交给独立协程。发送直接从 Wintun 驱动环读取，移除两道用户态出站队列。接收协程独立解密并写回 Wintun。
- Windows Mesh 复用已授权的 Babel 转发表和解析后的包头，按序批量提交同一 ESP SA 的等长就绪包。双向 TCP 满载时仍观测到上下行吞吐不对称。
- Windows 桌面显示节点通告前缀与隧道状态，可双击查看路由详情。命令行支持 `routes --destination <IP>` 查询匹配前缀。
- Gossip 合并部分 checkpoint 时间戳写入。Linux 的 Gossip UDP 收包和原始 ICMP 健康探测减少调度唤醒。
- 仓库新增 Photon Proxy 七层应用代理设计草案，涵盖可信节点发现、源节点选路与应用层代理链。此版本未实现或提供 `photon-proxy` 程序。

本版提供 Linux amd64 和 arm64 安装包及容器镜像，以及含 Wintun 的 Windows amd64 便携包。归档附有 SHA256 校验文件。
