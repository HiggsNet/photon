# Photon v0.6.6

- 新增按连接协商的 IKEv2 MOBIKE。Windows 和 Linux 主动接入节点可以在公网 IP 或 NAT 映射变化后迁移已有隧道。Windows 换网和唤醒时尝试保留 IKE/CHILD SA、Wintun 与 Babel 会话，迁移超时后重连。网关端口换代继续走 Rotate。
- Linux 网关通过签名 `ipsec/profile` 识别主动接入节点的漫游能力，逐连接应用本地接入策略。
- Windows 便携包拆分原生界面与后台，随包提供 `photon-windows-gui.exe`、`photon-windows.exe` 和 Wintun。配置和身份数据库沿用现有路径。
- 仓库的 FlClash 集成增加 Photon 配置与授权导入、代理选择、YAML 分流、后台按需提权和便携包构建及验签入口。

## 启用 MOBIKE

默认关闭。Linux 网关在现有 `ipsec:` 块内添加 `mobike: true`。Windows 客户端在现有
`gateway:` 块内添加 `mobike: true`。两端加载新配置后，通过 Gossip 同步签名 profile 并在 IKE_AUTH
中协商。Linux 主动接入节点可在 `ipsec.role: out` 下开启 `ipsec.mobike`。

已在 StrongSwan 5.9.13 和 6.0.7 的隔离环境验证端点迁移、ESP 业务恢复与后续换钥。
Windows 物理 Wi-Fi 与手机热点切换仍待实机验收。

本版提供 Linux amd64/arm64 安装归档与容器镜像，以及原生 Windows amd64 便携包。归档附带 SHA256 校验文件。
