# Photon v0.7.1

本版修复 Linux XFRM 接口查询或清理卡在内核后，Photon 事件循环持续等待、
Gossip 与管理请求无法正常处理的问题。提供 Linux amd64/arm64 归档和容器镜像，
以及统一版本号的 Windows amd64 便携包。

## 主要变化

- XFRM 查询、创建、删除、地址修改及维护放到后台执行，单次调用最多等待
  2 秒；调用者更早取消或超时时立即结束等待。
- 同一驱动及其副本共用一个执行名额。调用超时后，任务继续保留名额，直至
  内核操作真正返回；期间后续 XFRM 操作立即报错，避免重复清理、复用资源
  或累积挂起任务。连接变更在终止 SA、卸载密钥前检查挂起状态。
- 超时保留未完成清理的资源记录，报告原操作与开始时间。后台使用独立输入，
  迟到结果不会写回主循环；批量查询挂起时不再尝试其他查询路径。
- 驱动关闭时取消可取消的工作，并报告仍然挂起的操作，避免退出流程无限等待。

## 升级与恢复

v0.7.0 可直接升级，本版不新增数据库迁移或协议变更。更早版本仍需遵守
[v0.7.0 升级要求](https://github.com/HiggsNet/photon/blob/v0.7.1/docs/releases/v0.7.0.md)：
备份配置、身份和一致的数据库，旧 aggregate 或 Common schema 1 先使用
v0.6.6 迁移；原有混跑限制继续适用。

这项保护限制内核故障对 Photon 的影响，不会修复内核设备引用计数，也不能强制
结束 D 状态线程。已经卡死的节点可能仍需整机重启恢复；避免复发需要核实实际
运行的内核是否包含相应修复。不要将本版描述为 Linux 内核缺陷的修复。

## 验证范围

阻塞回归模拟不响应取消的删除和查询，覆盖等待上限、执行名额、输入及迟到结果
隔离，以及挂起期间的同步事件、管理查询与关闭行为。发布检查包括最低
Go 1.25.0 的全仓库检查、相关包竞态检查、常规 smoke 和 Windows 交叉构建。

正式发布流水线验证 Windows 原生运行、Linux 双架构归档及容器镜像，归档附
SHA256 校验文件。本次发布不包含故障节点部署、实际内核死锁复现或长期实网验收。
