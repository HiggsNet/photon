# Photon v0.7.10

本版减少 Babel 因短时丢包和延迟波动而频繁换路，并改进 Linux 上托管 BIRD 的升级和重载行为。

- Linux 和 Windows 的 Babel 默认每跳基础 cost 从 `100` 降到 `32`。带 Photon 补丁的 BIRD 和 Windows 客户端沿用 16 个 Hello 的丢包窗口，丢包惩罚的最低权重为 `128`。
- 带补丁的 BIRD 和 Windows 客户端默认等备路持续 `30 秒`至少优于当前路 `24` 点才切换。当前路失效时会立即选择可用备路。
- Photon 重启时默认接管仍在运行的托管 BIRD。原版 BIRD 拒绝补丁专用选项时，Photon 记录警告，省略这两个选项并校验兼容配置。校验通过后，本次路由更新照常生效。
- Release 提供 Ubuntu 24.04 和 26.04 的补丁版 BIRD，含 amd64、arm64 的 `.deb` 和对应源码。NixOS 可使用 `bird2-photon`，详见 [BIRD 安装说明](https://github.com/HiggsNet/photon/blob/v0.7.10/docs/new/bird-packages.md)。

附件还提供 Linux amd64/arm64 归档、Windows 原生便携包、Photon-FlClash 便携包和 EXE 安装版，以及对应的 SHA256 校验文件。GHCR 提供 Linux amd64/arm64 镜像。
