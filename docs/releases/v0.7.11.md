# Photon v0.7.11

本版让 Photon Services 管理的 TrustTunnel 默认使用 Mihomo 的 QUIC BBR 拥塞控制，作用于服务端发往客户端的流量。高延迟、易丢包线路的下载吞吐可能改善，效果取决于实际线路。

已有部署重新生成配置并执行 Compose `up` 时会重建 TrustTunnel 容器，现有连接会短暂中断。服务继续使用原有的 TLS 证书和指纹，客户端可用原有配置重连。

附件提供 Linux amd64/arm64 归档、Windows 原生便携包、Photon-FlClash 便携包和 EXE 安装版，以及 Ubuntu 24.04/26.04 的补丁版 BIRD 和对应校验文件。GHCR 提供 Linux amd64/arm64 镜像。
