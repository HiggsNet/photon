# Photon v0.7.13

- **Babel 隧道轮换**。让路的接口使用 BIRD 原生 `rxcost`，默认按两倍 `metric_base` 计算。默认基础值为 32，轮换时让路的接口为 64。验证新隧道时由新接口让路，排空时由旧接口让路。丢包和 RTT 仍参与选路。旧接口还有已选路由时，Photon 会推迟清理。
- **旧配置迁移**。显式设置的非零 `metric_staged` 或 `metric_draining` 继续生效。Photon 启动时会记录 `rotation_metric_override` 告警并标明实例。删除这两项或设为 0，即可使用新的默认规则。
- **被动 IPsec 链路**。已配置、等待对端拨入的链路会显示 `waiting_inbound`，避免因没有 SA 而重复加载配置。健康探测等对应的 CHILD_SA 安装后再启动。
- **Photon Proxy**。源码新增独立的 SOCKS5 代理，支持签名的多跳路径，以及通过本地控制 socket 更新客户端路径。可用 `make build` 构建，步骤见 [Photon Proxy 文档](https://github.com/HiggsNet/photon/blob/v0.7.13/docs/photon-proxy.md)。

附件提供 Linux amd64/arm64 归档、Windows 原生便携包、Photon-FlClash 便携包和 EXE 安装版、Ubuntu 补丁版 BIRD 以及 SHA-256 校验文件。GHCR 提供 Linux amd64/arm64 镜像。
