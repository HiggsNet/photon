# Photon v0.7.14

- **Photon Proxy v2**。同一节点可配置 Client、Relay 和 Exit。客户端从 Gossip 发现中继和出口，为每一跳指定公网 IPv4、公网 IPv6 或 Photon Mesh，并对整条路径签名。Relay 和 Exit 可复用 IPsec 地址公告，轮换代理端口。v2 使用独立的配置和 Gossip 记录，部署步骤见 [Photon Proxy v2 文档](https://github.com/HiggsNet/photon/blob/v0.7.14/docs/photon-proxy-v2.md)。
- **SOCKS5 管理面板**。已保存路径支持切换、删除，以及 Google HTTPS 204、UDP DNS 和 Cloudflare 4 MiB 下载测试。TCP 和 UDP 使用同一条路径。监听地址可指定本机 IP 或 IPv4 通配地址，开放给其他机器时需配置来源白名单。
- **大包健康探测**。可通过 `health.large_probe` 单独启用大包 ICMP 采样。Observer 按 Zone 展示大小包的丢包率、RTT 和历史。大包采样默认关闭，启用后也不会参与 Babel 选路或端口轮换判定。
- **IPsec MOBIKE 与启动顺序**。Linux 网关默认接受获准移动节点通过签名 profile 声明的 MOBIKE，可用 `ipsec.mobike: false` 关闭。Windows 切换配置时更新签名 profile 并复用传输身份。NixOS 的 Photon 服务在控制接口就绪后通知 systemd，服务配置生成器随后可通过该接口查询 IPAM。

附件包括 Linux amd64/arm64 归档、Windows 原生便携包、Photon-FlClash 便携包和安装版、Ubuntu 补丁版 BIRD 及 SHA-256 校验文件。GHCR 提供 Linux amd64/arm64 镜像。运行 Photon Proxy v2 需用此版本源码执行 `make build`，编译出的 `photon-proxy` 位于 `build/`。
