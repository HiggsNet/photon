# Photon v0.7.15

- **逐节点配置 IPsec**。在 overlay 的 `peer_overrides` 中，可为指定节点设置拨号角色和 IPv4、IPv6 拨号端点。角色覆盖沿用双方原有的选角规则。显式指定 `natt_port` 时，对端需使用固定端口模式。旧版节点仍按全局角色选角。 [配置说明](https://github.com/HiggsNet/photon/blob/v0.7.15/docs/new/config.md#overlay-link-policy)
- **IPsec 端口轮换**。被动端保留准备好的新代配置和 XFRM 接口，持续等待对端拨入。主动端遇到协商超时时保留可用的旧 SA，并在退避后使用同一份新代配置重试。
- **逐链路 Babel cost**。托管 BIRD 支持按 overlay、对端和外层地址族设置接收 cost 与 RTT 参数。端口轮换期间，新旧接口继续使用各自链路的设置。 [配置说明](https://github.com/HiggsNet/photon/blob/v0.7.15/docs/new/config.md#逐链路-babel-cost)
- **Photon Proxy v2**。代理进程校验并缓存授权目录，默认每 60 秒检查 daemon 的目录版本，并在本地应用已知的授权和租约过期时间。新增 `h2l4` 与 `h2l6`，可选定外层地址族，通过直接 IPsec 链路到达下一跳。端口轮换期间，新链路通过探测后接收新连接，已有连接可在旧链路上排空。目录 socket 协议已更新，使用 Proxy v2 的节点需同步升级 `photon` 和 `photon-proxy`。 [代理配置说明](https://github.com/HiggsNet/photon/blob/v0.7.15/docs/photon-proxy-v2.md)
- **Photon-FlClash**。代理模板发布或清理失败时保留 Photon 后台连接。模板支持离线编辑和重置。核心拒绝离线模板时，应用回退到内置规则，并继续保护内网直连。
- **Observer**。Health、Overlay 和 Gossip 列表按对端或域归组，详情可独立滚动。窄屏返回列表时保留原滚动位置。

正式产物包括 Linux amd64/arm64 归档、Windows 原生便携包、Photon-FlClash 便携包和 EXE 安装版、Ubuntu 补丁版 BIRD、SHA-256 校验文件，以及 GHCR 的 Linux amd64/arm64 镜像。Photon Proxy v2 可从本版源码执行 `make build` 生成 `build/photon-proxy`。
