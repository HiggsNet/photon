# Photon v0.7.16

- **逐链路 IPsec MTU**。`overlays[].peer_overrides` 支持按对端及外层地址族配置本机 XFRM 接口的 MTU。新建和轮换的接口会应用该设置，已建立的接口可原地修正 MTU 并保留 SA。 [配置说明](https://github.com/HiggsNet/photon/blob/v0.7.16/docs/new/config.md#overlay-link-policy)
- **Observer**。Zones 采用左表右详情，Gossip 隐藏已撤销节点。表格右对齐，节点名称按后缀排序。Overlay 同行展示 IPv4 和 IPv6 路径及轮换状态，Health 将问题、小包和大包丢包率、分地址族 RTT 集中展示在列表中。Routes 分为授权路由、IPAM 和授权错误三个标签页。
- **Photon-FlClash**。规则模板说明加入七种语言的可复制 AI 提示词，用于协助将已有 Clash/Mihomo 配置改成可导入的 Photon 规则模板。 [客户端说明](https://github.com/HiggsNet/photon/blob/v0.7.16/app/photon-flclash/README.md)

正式产物包括 Linux amd64/arm64 归档、Windows 原生便携包、Photon-FlClash 便携包和 EXE 安装版、Ubuntu 补丁版 BIRD、SHA-256 校验文件，以及 GHCR 的 Linux amd64/arm64 镜像。Photon Proxy v2 可从本版源码执行 `make build` 生成 `build/photon-proxy`。
