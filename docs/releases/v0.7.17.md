# Photon v0.7.17

- **Windows 支持 Photon Proxy v2**。Windows 后台支持 SOCKS5 客户端、中继和出口，复用 Linux 的代理配置和路径管理接口。逐跳 IPsec 直连使用请求所选地址族的已认证对端，可通过本地命名管道管理路径。 [Windows 配置](https://github.com/HiggsNet/photon/blob/v0.7.17/docs/photon-proxy-v2.md#photon-windows)
- **FlClash 路径和模板**。侧栏分为 Photon、路径、服务和模板。可在宽弹窗中选择、重排和测试多跳路径，编辑已有路径时保留 SOCKS5 端口。通过模板页手动应用已选路径、服务出口和自定义规则，模板可指定内置代理组顺序。设置和关于页显示 Photon 包版本。 [客户端说明](https://github.com/HiggsNet/photon/blob/v0.7.17/app/photon-flclash/README.md)
- **Linux 路径管理 Web**。每条路径用卡片展示 SOCKS5 地址和逐跳连接方式。新建和调整使用宽弹窗，节点目录与表单并排，测试结果显示在对应卡片里。FlClash 和 Linux Web 的中继与出口选择按 Zone 后缀排序并右对齐。 [管理界面](https://github.com/HiggsNet/photon/blob/v0.7.17/docs/photon-proxy-v2.md#management-api-and-web)
- **代理签名时钟容差**。已升级的中继和出口允许发送端时钟快慢各两分钟，签名有效期上限仍为 120 秒。接收端跨重启保留防重放状态。从旧版首次升级时，接收端要求签名签发时间晚于切换时点，时钟落后的发送端可能需要短暂等待。 [协议说明](https://github.com/HiggsNet/photon/blob/v0.7.17/docs/photon-proxy-v2.md#wire-format)
- **Windows IKE 诊断**。调试日志记录 IKE 收发、队列和超时判定，便于与网卡抓包对照。运行日志和共享 UDP 套接字的重绑改为后台处理。 [诊断说明](https://github.com/HiggsNet/photon/blob/v0.7.17/docs/photon-windows/ike-testing.md)

正式产物包括 Linux amd64/arm64 归档、Windows 原生便携包、Photon-FlClash 便携包和 EXE 安装版、Ubuntu 补丁版 BIRD、SHA-256 校验文件，以及 GHCR 的 Linux amd64/arm64 镜像。Linux 的 `photon-proxy` 可从本版源码执行 `make build` 生成。
