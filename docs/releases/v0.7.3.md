# Photon v0.7.3

本版包含 v0.7.2 的 Photon-FlClash 状态列表、规则模板和首次配置引导更新，
并修复 Windows 全新 Flutter SDK 初始化时，普通输出混入机器版本 JSON 导致
打包中止的问题。v0.7.2 的 GitHub 发布流程未完成，请使用本版安装包。
发布流水线统一构建 Windows 原生客户端、Photon-FlClash 便携包、
Linux amd64/arm64 归档及双架构容器镜像。

## 主要变化

- Windows 打包先单独初始化 Flutter，再读取机器版本 JSON；在解析前检查
  命令退出码，使初始化输出和实际命令失败都能正确处理。

- 隧道与 Gossip 节点按名称中的域名、地区分段倒序排列，使同域、同地区
  节点相邻；Gossip 列表隐藏已撤销节点。
- 同一网关的 IPv4、IPv6 外层隧道合并为一行，两个固定位置的标记分别
  表示对应隧道是否可用，点击仍可查看每条隧道的独立详情。
- 路由改为表格，按目标及源前缀聚合，展示下一跳、路由开销和路径数，
  点击可查看候选路径。后台观测补充下一跳地址与外层地址族；尚无实测
  RTT 时延，延迟列显示未知。
- 代理规则模板支持 DNS/TUN 选项与默认值合并，并遵循 FlClash 的对应
  覆盖设置；必要的直连规则、TUN 地址排除和网关 DNS 例外在覆盖后补齐。
- 模板导入旁新增处理说明，可查看保留、生成及应用接管的字段，并复制
  或导出示例 YAML。新建配置页说明入网步骤、本地节点密钥首次连接时
  自动生成，以及根公钥由管理员提供。
- Windows 双客户端共用同一份 Photon 后台和 Wintun，打包后核对摘要、
  校验文件与归档内容；前端回归在 Linux 执行，Windows 执行原生测试和
  实际打包。

## 下载与升级

- Photon-FlClash：`photon-flclash-v0.7.3-windows-amd64.zip`。
- Windows 原生客户端：`photon-v0.7.3-windows-amd64.zip`。
- Linux：`photon-v0.7.3-linux-amd64.tar.gz`、
  `photon-v0.7.3-linux-arm64.tar.gz`，以及对应 SHA256 校验文件。

v0.7.1 可直接升级，本版不新增数据库迁移或 Gossip 协议变更。升级时保留
原有 Photon YAML、身份数据库及 `.proxy.yaml` 模板；更早版本仍遵循
[v0.7.0 升级要求](https://github.com/HiggsNet/photon/blob/v0.7.3/docs/releases/v0.7.0.md)。

## 验证范围

本地已通过前端与本地化的 47 项串行回归、Flutter 静态检查、最低 Go 1.25.0
的全仓库测试与 vet、Linux 构建、Windows 交叉构建及安装脚本检查；两个 Nix
入口均从 VERSION 读取版本号。PowerShell 首次初始化输出及版本命令失败路径
已通过模拟验证。正式产物还需通过发布流水线的 Windows 原生测试、前端
回归、双客户端打包、Linux 双架构构建及归档校验。

本版的实际 Windows 桌面使用、双 TUN 数据面及长期运行仍需安装后验收。
版本发布不包含任何现有节点的部署或身份数据变更。
