# Photon v0.7.4

本版更新 IPsec 建链策略、Windows Babel 丢包代价，以及 Photon-FlClash
的代理入口、状态列表和配置迁移体验。

## 主要变化

- 将 IPsec 的 connect/deny 策略写入签名记录并通过 Gossip 广播；Linux 和
  Windows 建链前检查双方策略，保留角色选主和旧记录兼容行为。
- Windows Babel 根据 Hello 接收情况及 IHU 计算双向 ETX，让路由代价反映
  丢包并在恢复后回落；不新增 RTT 测量。
- 合并共享地址和端口的任播代理入口，保持入口名称与生成配置稳定；规则
  模板示例增加 OpenAI 分流组。
- 调整状态列表对齐、路由展开和代理地区列展示。
- Photon-FlClash 支持导入 YAML，复制配置、规则模板及已有身份；也可继续
  引用外部 YAML。停止 Photon 后可迁移当前配置到空目录，切换使用副本并
  保留原文件；身份数据库被占用或校验失败时拒绝复制。
- 全新 Windows 便携版使用程序旁的 data 目录，安装版使用 AppData；已有
  AppData 设置继续读取。新建配置的数据库路径相对 YAML 解析，内部配置
  选择相对应用数据目录保存，便于整体移动便携目录。

## 下载与升级

- Photon-FlClash：`photon-flclash-v0.7.4-windows-amd64.zip`。
- Windows 原生客户端：`photon-v0.7.4-windows-amd64.zip`。
- Linux：`photon-v0.7.4-linux-amd64.tar.gz`、
  `photon-v0.7.4-linux-arm64.tar.gz`，以及对应 SHA256 校验文件。

v0.7.0–v0.7.3 可直接升级，本版不新增数据库迁移。升级前备份 Photon YAML、
身份数据库及 `.proxy.yaml` 模板；更早版本仍遵循
[v0.7.0 升级要求](https://github.com/HiggsNet/photon/blob/v0.7.4/docs/releases/v0.7.0.md)。
新版本会应用对端公布的建链策略，混跑旧版时保留旧记录行为。手工设置的
绝对路径继续引用原位置；仅修改数据库路径不会搬迁身份文件。

## 验证范围

发布检查覆盖最低 Go 1.25.0 全仓库测试与 vet、Linux 构建、Windows 交叉构建、
常规 smoke、安装脚本检查及 Flutter 静态检查和相关回归。正式发布流水线
进一步执行 Windows 原生测试、双客户端打包和 Linux 双架构构建。

Windows 交互桌面、真实授权弹窗下的数据迁移及长期数据面仍需安装后验收。
版本发布不包含现有节点部署或生产身份数据迁移。
