# Photon v0.7.5

本版整理 Photon-FlClash 界面，首次提供 Windows EXE 安装版，并修复
Windows 隧道历史失败显示及 overlay 路径兼容性。

## 主要变化

- 顶部控制栏只保留隧道数量、连接和断开，统一对齐；配置路径和管理操作
  移入独立的设置标签，按当前配置、配置管理和数据目录分组。
- 配置编辑、导入、新建、授权导入、目录查看和迁移集中管理；连接期间
  限制配置修改和目录迁移。精简设置与代理说明，模板操作收进菜单，详细
  解释通过信息入口查看，并同步更新七种语言文案。
- 隧道详情按外层 IPv4、IPv6 分组，内网 IPv4、IPv6 路由独立标注，避免
  将公网连接方式和内网路由混淆。
- 已建立 IKE/ESP 的隧道不再把历史失败当作当前故障展示；原始诊断保留
  历史记录。overlay 按双方共同支持的当前路径判断兼容性，保留隧道地址
  规则一致性检查。
- Photon-FlClash 新增 EXE 安装版，提供开始菜单、可选桌面快捷方式及
  卸载入口。运行中的程序会阻止替换；覆盖安装和卸载保留用户配置及身份。
  Photon 构建的更新入口指向 Photon Release，禁用上游程序的自动替换。

## 下载与升级

- Photon-FlClash 安装版：`photon-flclash-v0.7.5-windows-amd64-setup.exe`。
- Photon-FlClash 便携版：`photon-flclash-v0.7.5-windows-amd64.zip`。
- Windows 原生客户端：`photon-v0.7.5-windows-amd64.zip`。
- Linux：`photon-v0.7.5-linux-amd64.tar.gz`、
  `photon-v0.7.5-linux-arm64.tar.gz`，以及各产物对应的 SHA256 校验文件。

v0.7.0–v0.7.4 可直接升级，本版不新增数据库迁移。升级前备份 Photon YAML、
身份数据库及 `.proxy.yaml` 模板；更早版本仍遵循
[v0.7.0 升级要求](https://github.com/HiggsNet/photon/blob/v0.7.5/docs/releases/v0.7.0.md)。
安装版默认使用 AppData，便携版继续沿用现有数据目录规则；安装程序不会
自动搬迁便携版数据，可通过设置页导入或引用原配置。

## 验证范围

发布检查覆盖最低 Go 1.25.0 全仓库测试与 vet、Linux 构建、Windows 交叉构建、
常规 smoke、安装脚本检查、Flutter 静态检查和相关回归。正式流水线还会
执行 Windows 原生测试、双客户端打包、EXE 安装生命周期及数据保留检查，
并构建 Linux 双架构归档和容器镜像。

界面预览覆盖中文宽、窄窗口；真实 Windows 桌面的交互及长期数据面仍需
安装后验收。版本发布不包含生产节点部署或生产身份数据迁移。
