# Photon v0.7.8

本版修复 Windows 的网关 DNS、已建立隧道在 DNS 刷新时的连续性，以及唤醒后
的重连和界面状态查询。

## Windows 隧道

- 网关域名在后台并行解析。每个域名独立超时和重试，后续候选可以随结果
  返回进入拨号。诊断会保留解析失败原因，并在可用时显示 DNS 服务器和网卡编号。
- 已认证的隧道根据握手确认的对端与当前签名记录继续复核。暂时缺少 DNS
  结果时保留已建立的会话，签名授权撤销或过期时退役对应隧道。等待 DNS
  的候选会在解析恢复后自动尝试连接。
- Windows 唤醒或网络变化触发重绑时，从配置的初始重试间隔重新尝试，
  默认 1 秒。此后的连接失败仍按配置增加等待时间。

## Windows 客户端

- Photon-FlClash 和独立 Windows 界面遇到暂时性的状态查询超时时保留
  Photon 后台。迟到的响应会正常读完，后续查询可以继续更新界面。
- Photon-FlClash 在状态暂时不可用时撤下旧的代理目录，并在查询恢复后
  重新载入。手动停止仍会清理所属的后台进程。

## 升级

升级可保留现有配置、身份和数据库。升级前请备份，并参见
[兼容性说明](../operator-compatibility.md)。

附件提供 Linux amd64/arm64 归档、Windows 原生便携包、Photon-FlClash
便携包和 EXE 安装版，以及对应的 SHA256 校验文件。GHCR 提供 Linux
amd64/arm64 镜像。
