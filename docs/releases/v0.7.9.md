# Photon v0.7.9

本版简化 Photon-FlClash 自动生成的节点名称。

- 固定节点只显示域名第一段，能识别地区时加旗帜，例如 **🇯🇵 jtti-hnd**。
- 任播节点只显示覆盖范围，例如 **🌐 global** 或 **🇭🇰 hk**。
- 节点卡片在标题下方显示协议。同协议的出口重名时，标题会加短标识，方便分别选择。默认配置和自定义模板都使用新名称。

升级可保留配置、身份和数据库。旧版按节点名保存的手动出口在配置首次刷新后可能需要重选。

附件提供 Linux amd64/arm64 归档、Windows 原生便携包、Photon-FlClash 便携包和 EXE 安装版，以及对应的 SHA256 校验文件。GHCR 提供 Linux amd64/arm64 镜像。
