层推荐本轮实际
planner / spec 名 永远 phx<id> 对齐删掉 applyPolicyDeviceOverride
owner / teardown 资源名可校验 对齐lo 不再进入 instance
对端路由 Ensure 不变量 对齐删掉 optional 接口；Adopt 也走 Ensure；错误不再吞
daemon 匹配 只消费 Inspect 结果 对齐看 SharedAttachment，不读 config
VICI if_id 构造时决定 半对齐仍是 driver 字段 + load 时 if policy
XFRM 实现 两个类型 未做一个类型 + Backend flag + 内部 if
xfrm_backend 出现次数 两个构造函数 仍多config → group + 两个 driver 字段
factory 返回不同 adapter 未做只赋值 driver.Backend
一句话：调用面已经是推荐形状（phx 资源名、Ensure 含路由、daemon 不读 backend）。 实现面还是「一个 driver 里的 flag」，不是「两个 adapter」。 这是文档里写明的停点——第 4 步拆类型时，调用方不用再改。
